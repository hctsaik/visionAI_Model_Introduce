# WI-039 初學者端到端 UX 獨立審查

日期：2026-09-13。審查者 ux_flow；唯讀，未改產品或 Git。

## 結論

目前可作為教學試用版；建議定版前只修一個入口問題。新版需求導向 PoC 本身能走完，沒有理由再重做選型流程。其餘兩項屬後續教學體驗改進，不能用自動測試宣稱學習效果已驗證。

## 覆蓋與方法

在全新瀏覽器 context，以本機正式輸出 `http://127.0.0.1:8000/docs/index.html` 實際操作；桌面 1440×900、手機 390×900，各走首頁主要按鈕 → ChArUco → 展開情境解釋 → 課程操作卡 → PoC 固定格位漏裝四題 → 結果。另抽看 DINO detector 全頁可見文字及首屏。觀看桌面／手機首頁 PNG、手機 PoC 結果 PNG；保存文字、按鈕位置及 JSON 證據。這不是 58 課全查，也不是真人可用性測試。

## 1．定版前應修：首頁未讓需求導向使用者找到新版助手

步驟：新 context 開首頁，不預先知道 `#view=poc`。桌面／手機主 CTA 均為「從第一張教學圖開始：ChArUco」，實按確實前往 `#view=lesson&lesson=charuco&slide=1`。首頁正文所有按鈕沒有直達 PoC 的選項；入口在側欄第六項「我的 POC 選型畫布」，手機須先打開漢堡選單。

影響：只知道現場需求的人，仍容易以為必须先學／選模型，無法發現已完成的需求推導功能。這是主流程的入口沒有連上，不是 PoC 內容又失敗。

最小修改：首頁主要操作加入「不知道選什麼？從現場問題找方法」直達 `#view=poc`，保留讀教材入口；側欄命名與新版「需求導向／試做助手」一致。不需移除 ChArUco 課程或更動全部頁面。

證據：`ux-1440-home.png`、`ux-390-home.png`、`ux-1440-home-buttons.json`、`ux-walk-evidence.json`。

## 2．可之後改：學習檢核出現很晚，完成度只能代表自行標記

步驟：從首頁 CTA 進 ChArUco，尚未阅读便可按「完成本主題」成為「✓ 已完成」；其後才向下找到「看解釋與可接受的取捨」。初始未展開時，該檢核位於桌面約 y=4234、手機約 y=7696。實際點開能看到治具平移與換鏡頭的差異解釋，內容具有遷移判斷價值。

影響：不是按鈕錯誤，但「已完成學習」不能当作理解程度證據。長頁讀者也可能錯過最有價值的應用判斷。

建議：可把完成標記稱為「已讀／自行標記完成」，或在課首提供「試著判斷」頁內跳轉。保留自由閱讀，不要求強制答題才能標記完成。是否加入選項與回饋，應由少量初學者試用結果決定，這不阻擋本輪定版。

證據：`ux-walk-evidence.json`、`ux-390-learning-check.txt`、`ux-390-learning-check.png`；抽查網址 `#view=lesson&lesson=charuco&slide=1`。DINO 也見課首完成按鈕，但未把此位置數值外推到全部課程。

## 3．可之後改：PoC 結果的理由較重複，小實驗在手機需繼續捲動

步驟：PoC 選漏裝 → 固定格位 → 原圖可辨 → 正常照片多。結果正確顯示「先試對齊固定位置，再逐格檢查有無」，不要求先選模型；「為什麼」列出一條推導理由及全部四項問答，而右側／下方另有答案路徑。

影響：內容可讀且操作成功，但手機第一屏大部分篇幅是重複答案；具體小實驗較晚才出現。

建議：日後可保留一至兩條因果理由，把完整答案放在既有可修改路徑，讓「第一個小實驗」更早露出。這是精簡呈現，不應另起整套流程改版。

證據：`ux-390-poc-result-viewport.png`、`ux-390-poc-result.txt`。另外核對 `ux-focus-evidence.json`：正常操作後結果標題 top≈102px，固定頂欄 bottom≈72px，沒有標題被遮住；element screenshot 自動捲動造成的遮擋未列為產品缺陷。

## 本輪確認有效之處與限制

- 桌面／手機實際由課程到 PoC 都能走完；模型只留為舊課程筆記，不主導需求分支。
- 先選答案再按繼續，結果能說出方法、理由、缺口及比較實驗；固定格位情境沒有強推偵測模型。
- 所走結果頁無水平溢出；沒有把「沒有溢出」當成所有文字與圖像都已通過教學驗證。
- 自動化走查無法證明初學者能自行發現入口、讀懂全部模型或把知識用於現場。後續可找 2–3 位未接觸教材的人，觀察是否自行找到助手、說出選路理由及第一個實驗，再决定是否追加改版。

審查產物：`inspect-ux.py`、`walk-ux.py`、`check-focus-ux.py` 只產生本工作目錄的截圖／文字／JSON，沒有寫入教材。
