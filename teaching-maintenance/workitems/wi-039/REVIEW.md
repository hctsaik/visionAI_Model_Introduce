# WI-039：Multi Agent 定版審查結論

2026-09-13。結論：目前可公開使用；建議先完成一次有限的定版收尾，再凍結版本。沒有證據支持重做整套網站，也沒有足夠證據宣稱全部教材逐字逐圖已通過最終驗收。本輪只審查、記錄，沒有修改或重新發布網站。

## 審查範圍與基準

- 三位獨立 Agent：教學語意、新手操作、交付一致性；主 Agent 反查原始程式、編譯資料、實際截圖與公開版本。
- 公開 HTML 與本機 docs 逐位元一致，SHA-256 `561617fdc2b77614a024b573857597a48632c5b51eba910d536e6dc11652c8f3`。基準為 e6b415f 功能版、d16f6be 紀錄版。
- 教學內容分層抽查 18 課、7 家族；對 58 課做特定欄位模式掃描。四課的展開因果鏈另以瀏覽器確認，沒有把未渲染欄位誤當可見缺陷。
- 公開 home/library/poc 在 1440px 與390px 檢查：未見橫向溢出、破圖或 JS 例外。UX Agent 另實走首頁→ChArUco→情境解析→PoC→結果，兩種寬度均可完成。
- 未做：319 張插圖逐張新評分、58 課逐字審核、135 個外部 URL 全檢、真人學習試驗及模型推論。故不給全站總分，不宣稱已達量表逐圖 >90 門檻。

## 定版前收尾

| 優先 | 已確認問題 | 最小處理與驗收 |
|---|---|---|
| 1／資料保護 | 備份匯入接受無關 JSON；匯入 `{"hello":"world"}` 並同意取代後，原本 completed、bookmarks、poc 被清空，仍顯示成功。 | 先驗備份結構及支援版本，再確認取代。錯檔、陣列、損壞結構及取消操作必須保留原狀，合法新舊備份可還原。 |
| 2／新手入口 | 首頁主要 CTA 是「從第一張教學圖開始：ChArUco」，main 沒有直接到需求助手；手機 PoC 入口藏於導覽選單。 | 首頁清楚提供「從現場問題找方法」直達助手，保留依課程閱讀的入口。未提供模型名的新手能從首頁開始選需求。 |
| 3／教學一致性 | AnomalyGPT 展開機制混入應用端 evidence／SOP schema，與新版主線的原模型角色說明不一致；ConvNeXt、V-JEPA 的部分機制標題／內文仍錯位。 | 同步修正三課的展開因果鏈，標清原模型與選用整合，標題、操作、輸出需一一對應。驗收同時讀主線與展開區。 |

第 1 項為已重現的功能問題；第 2 項為針對本網站新手定位的產品收尾；第 3 項主要在收合參考區，不表示新版主圖全部錯誤。詳細原句、欄位與重現步驟見三份分工報告。

## 可留待後續，避免無限擴充

- 因果鏈中 116 個通用 why、164 個 WI 開頭設定 anchor 可逐步清理；「因為：由本課核心機制連接工作用途」沒有提供實際理由，工單編號也不是現場設定。少量確定的簡體字一併校對。
- 學習檢核可增加明顯跳轉或調整位置；「已完成學習」可註明自行標記。沒有理由要求先新增考試平台或強制答題才能定版。
- PoC 結果可精簡重複的答案回述，讓手機讀者較早看到小實驗；現有流程可完成，不需要重新設計。
- 找少量未熟悉模型的使用者，從首頁完成一個需求案例，說明為什麼採用該方法及仍缺什麼。這能補真人理解證據；Agent 走通流程不能替代這項證據。

## 保留與停止擴張的依據

需求式助手已能依現場條件變更方法，主流程不要求模型選擇；舊稿與新推導分離。抽查的 DINO、YOLOE、DINOv2、ResNet 先前缺口已修正，不重報舊問題。核心「候選需回原始證據核對」定位成立，沒有必要再擴模型數量來證明完成。

建議先排上述三項收尾，通過各自驗收後可將該版作為穩定發布基準；若宣称全站逐張教學品質達標，仍需補齊相應評估，而不是把本次抽查擴張成全數通過。
