# WI-039：發布一致性、進度與驗證證據審查

日期：2026-09-13。唯讀審查；沒有修改產品、使用者真實進度或 Git。瀏覽器核對使用獨立 headless Edge context 與本機 docs。

## 定版前必修：錯誤 JSON 可清掉整份進度

位置：`tools/build_interactive_learning_html.py:3034`–`3039`，`importProgress()`。

重現：先有 `completed.resnet=true`、收藏 `resnet` 及 PoC 草稿；於 PoC 的備份區匯入 `unrelated.json`，內容為 `{"hello":"world"}`，接受覆蓋確認。頁面顯示「已匯入進度。」；localStorage 實際变成 `completed:{}`、`bookmarks:[]`、`poc:{}`，並留下無關的 `hello` 欄位。已以本機 docs 實際操作重現。

原因：JSON 解析成功且是 object 就當有效進度檔，沒有驗證備份識別、版本及最低必要結構；覆蓋後 `pocUndo=null`，不能用 PoC 撤銷恢復。覆蓋確認不能替代「這是不是本課程備份」的格式驗證。

最小修正：先驗證有效的本課程備份結構及支援版本，再顯示取代確認、一次寫入；非本課程 JSON、陣列或損壞結構必須拒絕且原進度完全不變。保留已知舊版備份的相容路徑。補錯檔、取消、合法舊／新版匯入測試。

現有 `tests/test_poc_workbench.py:160` 的 roundtrip 僅驗證網站自己匯出的合法檔；不能替錯檔拒絕背書。本項屬資料保護問題，建議定版前修正。

## 已核對，未列為阻礙

- 本機 `interactive-learning.html` 與 `docs/index.html` 逐位元相同，58 課 course-data 均存在。公開 HTTP 雜湊由主 Agent 另驗，本審查不重複聲稱公開一致。
- 遍歷 course-data 的 2031 個本地檔案樣式引用；唯一不存在的直接相對路徑來自 232 個 `activeAsset` 作者 metadata。其餘實際資產欄路徑均存在。`activeAsset` 不是頁面直接取圖路徑，沒有將它誤報成破圖。這是磁碟存在性核對，不等於所有 HTTP 或圖像內容驗證。
- ResNet 實頁存在可見的「完成本主題」按鈕。完成度為使用者自我標記：`toggleComplete()` 在 builder:2488 起只切換時間戳；練習為展開解析（builder:2755），不自動判分。未發現現行頁面聲稱這是考試通過率，因此不要求新增考試系統才能定版。
- WI-038 報告清楚分開規則測試、瀏覽器測試、實頁截圖、公開發布與使用者審閱。15 項規則測試中，全可達答案掃描檢查課程 ID、非空結果、未知／缺資料狀態等不變條件；這不是逐路線人工選型評估或模型實測。報告沒有據此宣稱實際辨識準確度。
- `tests/test_interactive_navigation.py` 三項是模板字串斷言，不是三項獨立瀏覽器導航操作。可作回歸護欄，但最終報告須維持此範圍；無需為「全面定版」而把既有測試全部改寫。

## 可選改善，非定版阻礙

首頁「已完成學習」可進一步註明為自行標記，避免讀者以為經過測驗評分。現有明確的完成按鈕及解析式練習已使操作有合理解釋，故不將措辭優化列為必修。

## 覆蓋限制

本子審查核對版本檔、資產路徑、進度／匯入邏輯、現行測試涵義與少量實頁操作；未逐一連線核對 135 個外部來源 URL，未覆核所有教學圖片，也未進行真人理解測試。主 Agent 的公開頁與 UX／內容兩項獨立審查應與本紀錄合併判斷。只找到上述一項實際定版阻礙，不為湊數新增需求。
