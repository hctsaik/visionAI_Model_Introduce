實作時逐步核對

主圖已在上方第一遍。這裡只核對每一步要鎖定的設定與為什麼，不再重貼同一張圖。

1
先稽核 auxiliary prompt-learning 與 target exclusion

保存 auxiliary data IDs、taxonomy、license、split、target exclusion、source anomaly policy 與 prompt-learning checkpoint。

因為：zero-shot 指沒有用 target training，不代表沒有學過的 prompt state；target leakage 會讓 transfer 結論不成立。

設定核對：工程圖核對：auxiliary split → learned prompt tokens

2
鎖定 learned normal/anomaly text embeddings

在鎖定的 CLIP/text encoder、tokenizer、template、context length 與已宣告 adaptation state 下得到 normal 與 anomaly prompt embeddings。

因為：文字側的微小改動可翻轉 similarity margin；沒有 revision 就無法重播同一個候選。

設定核對：工程圖核對：normal/abnormal prompt embeddings

3
讓 ROI 的 global/patch feature 和 prompts 比較

固定 ROI/image preprocessing 後，由 frozen 或已宣告 adapted 的 CLIP image encoder 產生 global 與 selected patch features，計算各自對 normal/anomaly prompt 的 normalized similarity margin。

因為：局部 evidence 來自特定 feature 層和 patch resolution；不是 VLM 的自由文字能力，也可能漏掉 tiny defect。

設定核對：工程圖核對：CLIP patch features → normal/anomaly margins

4
margin map 先本地校正，再交給 review

patch margins 經固定 interpolation、smoothing、aggregation、calibration、threshold/abstain policy 形成 candidate map 和 action trace。

因為：margin 的大小本身不等於 defect probability；prompt transfer、domain gap 與 map rule 都可能改低 FPR。

設定核對：工程圖核對：margin map → local calibration → gate

正確下一步：驗effective pixels與domain coverage；對低FPR/結構問題使用specialist evidence或HOLD。

目前做法

原始建置項目

這些設定要一併保存

輸入與版本：先分清輔助訓練與目標驗證，再追 p 的圖文比較。；關鍵機制：以輔助正常／異常資料和區域標註，聯合整圖與局部監督學習物件無關的狀態提示。CLIP 骨幹權重固定，文字提示可學，DPAM 調整注意力以保留局部語意；目標影像與兩種文字表示比較，再整合多層局部線索。目標零樣本不代表模型從未訓練。；獨立驗證：量 target holdout 的 prompt variance、margin distribution、low-FPR escape、false reject、review load、patch evidence 與完整 P95。；失敗處理：看不清細節先改善取像；位置或文字矛盾就回原圖覆核。

原始選型條件：WinCLIP 用人工狀態文字與視窗，WinCLIP+ 可加正常參考；AnomalyCLIP 使用輔助資料學到的提示；AnomalyGPT 加入內建定位與對話。只有正常品可先評估參考路線，訓練型方法要先備妥已訓練模型。固定硬體、解析度與漏檢要求，比誤報、延遲和覆核量；位置圖不等於精密輪廓或尺寸。
