模型專屬因果鏈

實作時逐步核對

主圖已在上方第一遍。這裡只核對每一步要鎖定的設定與為什麼，不再重貼同一張圖。

1
把 ROI 轉成被鎖定的多尺度 feature

測試與 normal ROI 經固定 image encoder、layers、ROI/resize/normalization，輸出 selected input features。

因為：encoder checkpoint、layer、feature alignment 和 image recipe 定義 inversion 的語言；改其中一項會改 residual 與成本。

設定核對：工程圖核對：image encoder → selected features

2
將空間樣式轉成 decoder 控制

rescaling upsampler 與 style translator 將 feature 轉為空間相關的 scale/shift controls，和 constant query 一起送入 SSM decoder。

因為：InvAD 的 identity 不是泛稱『重建』，而是以 style modulation 與固定 query 限制 feature inversion path。

設定核對：工程圖核對：rescale → style translator → constant query / SSM

3
一次 forward 得到 normal-like recovered features

normal-trained SSM decoder 產生對應尺度的 recovered features，並保存 checkpoint、stack/channel、loss、seed 與 class sampling policy。

因為：decoder 容量與多類別 coverage 共同決定什麼能被當作正常重建；不是所有低 residual 都代表安全。

設定核對：工程圖核對：SSM decoder → recovered feature

4
輸入與 recovered feature 的差距成為候選

以鎖定 distance、scale weights、resize/smoothing/mask、aggregation 和 threshold，將 residual 變成 map 和 image candidate score。

因為：distance 與後處理會改定位和低 FPR；local feature residual 也不會自動檢查缺件、數量或關係錯誤。

設定核對：工程圖核對：feature residual → map → evidence gate

失效案例、選型與小規模試做

什麼情況不能相信它？

這一區保留完整工程條件，供準備實作或驗收的人逐項核對。

decoder 太有能力或 normal support 受污染

可能看到：異常 feature 可能被 recovered 得太好，或污染型態被學成正常，殘差變小而漏檢。

正確下一步：HOLD；保存容量、loss、class sampling 與 contamination audit，檢查 real escaped defects 而非只看平均 loss。

style／illumination／view drift 或多類別 coverage 不平衡

可能看到：合法新樣式可能讓 residual 升高，稀有類別也可能被大宗類別的訓練偏好掩蓋。

正確下一步：按類別、lot、view 分層檢查，保存 style/encoder state 與 per-class future evidence。

tiny defect 小於有效 feature 尺度，或目標是 global logic

可能看到：rescaling、stride、smoothing 可抹掉小訊號；feature residual 不會自動驗缺件、數量與關係。

正確下一步：先驗 effective pixels；對結構／規則問題改用適合的 specialist path。

POC 第一件事：先證明 low residual 沒有把異常藏起來
固定 encoder/layers/freeze policy、rescaling、style translator、constant query、SSM stack/channels、normal IDs/category sampling、loss、seed 和 checkpoints。
鎖 feature distance/normalization/scale weights、map resize/smoothing/mask、aggregation、calibration、threshold 和 evidence trace。
按類別、challenge/future/drift split 比較 escape、false reject/review load、local/global localization、P95/P99、memory 和 style/decoder ablation。
目前做法

固定 encoder/layers、rescaling、style translator、constant query、SSM decoder、class roster、residual rule 與 per-class calibration。

要量什麼

按類別量 escape、normal-style false reject、review load、localization、style/decoder ablation、P95/P99 與 drift。

反例測試

以未涵蓋光澤／view mode 與 decoder-capacity ablation 測試，確認高 residual 不會被直接說成 defect，低 residual 也不會掩蓋 known defect。

多類別 AOI owner、Vision ML owner、品質 owner
