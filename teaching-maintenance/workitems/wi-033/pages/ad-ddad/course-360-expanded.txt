看解釋與可接受的取捨

更強保留原圖可能減少正常孔邊變形，也可能把刮傷一起留下；減少步數能改變時間與恢復品質，不能預設雙贏。用獨立正常與真缺陷，分開驗證像素／特徵兩項、引導與步數，量完整延遲和覆核量；只在同一漏檢要求下選擇可接受設定。

實作時逐步核對

主圖已在上方第一遍。這裡只核對每一步要鎖定的設定與為什麼，不再重貼同一張圖。

1
鎖定 conditioned diffusion 的正常重建契約

正常 support、已宣告 defect／synthetic／generated-example policy、image recipe、start noise、schedule、target-conditioning rule/strength、sampler、steps、denoiser checkpoint 和 precision 一起版本化。

因為：換 sampler、noise 或 steps 就會改重建行為、成本與可重播性；它們不是可以在展示時自由替換的參數。

設定核對：工程圖核對：noise + target condition → conditional denoiser

2
由測試輸入得到 normal-like x-hat

測試 x 依鎖定 sampling path 生成 x-hat，並保存完整 input/reconstruction trace。

因為：x-hat 是比較對照而不是 ground truth；它可以保留 defect、擦掉正常微結構或產生假紋理。

設定核對：工程圖核對：conditioned reconstruction x-hat

3
分別量 pixel 與 feature residual

比較 x 與 x-hat 的 pixel residual，並以固定 feature extractor／adaptation path 比較 feature residual，再記錄各自 normalization。

因為：pixel 對外觀變動敏感，feature 對細小訊號或 domain mismatch 有盲區；把它們混成單一無來源分數會失去可診斷性。

設定核對：工程圖核對：pixel map + feature map

4
以固定規則融合為候選 evidence

兩張 map 經 resize、smoothing、mask、fusion weights、aggregation、calibration 和 threshold 成為 candidate map 和 review trace。

因為：normalization 與 fusion 可以改低 FPR，即使每張 component map 看起來合理；需要真實 holdout 驗證。

設定核對：工程圖核對：dual residual fusion → gate

什麼情況不能相信它？

這一區保留完整工程條件，供準備實作或驗收的人逐項核對。

target conditioning 保留、抹掉或幻覺出結構

可能看到：平滑重建不代表正確；defect persistence、erasure 和 normal detail loss 都可能扭曲 residual。

正確下一步：HOLD；保存五聯 evidence，在真實 challenge 檢查 escaped defects 與 false reject。

pixel 對位/照明敏感，feature extractor/domain adaptation 偏差

可能看到：pixel map 可被 acquisition state 主導，feature map 又可能忽略細小 defect 或過擬合 generated protocol。

正確下一步：分開報告兩張 map、no-adaptation ablation、ROI/registration/illumination tests 和 real holdout。

sampling schedule、steps、fusion 或 drift 未鎖定

可能看到：不同設定有不同延遲、重建和 low-FPR；看似同一模型的比較其實不是同一 operating point。

正確下一步：保存 sampler/steps、fusion、calibration、hardware 與完整 P95/P99；改動後重新 qualification。

原始建置項目

這些設定要一併保存

輸入與版本：原圖條件引導多步恢復，再整合像素與適配特徵差異。；關鍵機制：先以正常資料訓練去噪模型，並用正常／近似恢復影像做特徵適配。測試時以原圖 A 為條件，逐步去噪得到恢復估計 R；像素差異與適配特徵差異加權整合，產生異常位置圖。原圖條件不是正常真值，也沒有額外學習式分割頭。；獨立驗證：量 pixel／feature component 行為、persistence／erasure、low-FPR escape、false reject、review load、no-adaptation baseline 與完整 P95/P99。；失敗處理：先查缺陷可見度與正常涵蓋，再查恢復設定和分數來源。

原始選型條件：DiffusionAD／DRAEM 把原圖與恢復圖一起交給學習式定位網路；DDAD 整合像素差異與適配特徵差異。前兩者需要合成異常與定位訓練，DDAD 則需正常去噪與特徵適配。在同硬體、解析度與漏檢風險要求下，比誤報、延遲和人工覆核量；沒有共同實測就不排名。
