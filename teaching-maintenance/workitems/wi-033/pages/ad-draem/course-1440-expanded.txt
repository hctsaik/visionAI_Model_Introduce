看解釋與可接受的取捨

先查原圖是否看得見細刮傷、正常光澤是否允收，以及合成外觀是否只教會色斑。用獨立真實正常與缺陷比較取像、合成設計和候選模型；提高門檻可能減少誤報卻增加漏檢。RD4AD 可作特徵路徑對照，AE 可作殘差基準，選擇須連同時間與覆核成本驗證。

實作時逐步核對

主圖已在上方第一遍。這裡只核對每一步要鎖定的設定與為什麼，不再重貼同一張圖。

1
用可追溯規則產生合成異常對

正常 ROI 依 source texture／noise、Perlin mask、幾何／色彩 transform、opacity 與 blending 生成 corrupted image I_a 和 synthetic mask M_a。

因為：mask shape、覆蓋率與混合方式會決定模型最容易學到哪種異常外觀；未版本化的 simulator 使結果不可比較。

設定核對：工程圖核對：normal ROI + synthetic recipe → I_a／M_a

2
學一條正常重建路徑

reconstruction network 將合成污染圖重建為 normal-looking image，使用鎖定 SSIM／L2 等目標與 normal support recipe。

因為：重建提供的是對照訊號，不是最終判斷；它也可能抹掉正常微結構或保留真實異常。

設定核對：工程圖核對：corrupt image → reconstruction

3
讓辨別器同看原圖與重建

將 I_a 與 I_r 的 joint representation 送入 discriminative segmentation network，訓練輸出 synthetic anomaly map；測試時改用 test image 與其 reconstruction。

因為：DRAEM 的 local evidence 來自辨別式 joint embedding，而不只是把兩張圖相減。

設定核對：工程圖核對：original + reconstruction → segmentation map

4
把 map 變成候選，並回到真實證據

預測 map 經 versioned smoothing、resize、ROI mask、aggregation、calibration 與 threshold 形成 candidate score 和 review trace。

因為：後處理可掩蓋小 anomaly 或放大合成式雜訊；真實 challenge 及低 FPR 證據比合成 mask IoU 更重要。

設定核對：工程圖核對：map postprocess → evidence gate

什麼情況不能相信它？

這一區保留完整工程條件，供準備實作或驗收的人逐項核對。

synthetic texture、mask 或 blending 偏離真實 defect

可能看到：segmentation 可能只辨認 simulator artefact，真實低對比或製程特有缺陷漏檢。

正確下一步：HOLD；記錄 synthetic recipe/provenance，使用真實 challenge、failure images 與 error taxonomy 驗證 transfer。

reconstruction 抹掉正常細節或保留異常

可能看到：joint input 的差異可能造成 false reject 或 defect escape，僅看重建漂亮與否無法判斷。

正確下一步：同步審查 input/reconstruction/map/decision；以正常與真實缺陷的三聯證據校正。

registration／照明變化、tiny defect 或 global logical anomaly

可能看到：外部變化像合成 corruption，或局部 visual supervision 無法表達缺件與關係錯誤。

正確下一步：先查 acquisition state 與 effective pixels；對 logical anomaly 使用結構／規則型方法。

POC 第一件事：驗證模型學到的是缺陷機制，不是合成捷徑

目前做法

要量什麼

原始建置項目

這些設定要一併保存

輸入與版本：先看原圖 A 與重建估計 R 如何共同進入學習式判別器。；關鍵機制：正常原圖提供重建目標，合成區域 mask 提供定位目標。推論把待測原圖與重建一起交給判別器，不需要提供 mask。；獨立驗證：量 real critical-defect recall、low-FPR escape、false reject、review load、synthetic-to-real gap、failure images 與完整 P95。；失敗處理：合成樣本成功但真實細刮傷漏檢時，先查取像與合成外觀涵蓋。

原始選型條件：能設計合成異常並訓練重建與判別兩個網路時，可評估 DRAEM；以 AE 作像素重建基準、RD4AD 作特徵重建對照。換產品需重查正常資料、合成外觀與訓練適配；用相同未見真實正常／缺陷、硬體與解析度比較漏檢、誤報、時間與覆核量。

原始失效邊界

下列情況不可忽略

合成外觀可能與真實缺陷不同；重建和判別都可能失敗，必須用未見真實影像查誤報與漏檢。

工程結論
原始影像、重建估計與判別網路的可疑位置圖，用於定位覆核；不直接提供真實缺陷機率、精密輪廓、尺寸或自動放行。
