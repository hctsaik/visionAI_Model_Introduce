# WI-041：PoC 決策、保存與備份定版審查

日期：2026-09-13。此次唯讀產品審查，新增審查腳本與證據，沒有修改產品或 Git。以現行 docs 執行獨立 Edge context；公開版本與資產一致性由主 Agent 另核對。

## 結論

在本輪覆蓋範圍內，沒有找到新的定版阻礙。WI-039 的錯檔清除問題目前已被拒絕匯入與回滾檢查防住。合法 v1／v2 備份及現版帶 backupType 的備份可還原；新流程不依賴模型選擇。

這是功能與前提正確性判定，不是所有推薦已經現場模型實測，也不代表使用者成品認可。

## 實際執行證據

- `reliability-rules.txt`：15 項 Node 決策測試，exit 0。
- `reliability-hardening.txt`：6 項瀏覽器測試，含 9 種無效備份、v1／v2、取消、新版往返、儲存失敗回滾，以及兩種寬度首頁入口；exit 0。
- `reliability-poc.txt`：13 項瀏覽器測試，含六情境子測試；exit 0。
- `reliability-evidence.json`：額外的未按繼續保存、未 blur 的交接文字立即匯出／重整、深色主題往返、匯入殘留舊分支值均通過，無 pageerror。
- `decision-path-coverage.json`：實際枚舉 1156 條可達完整答案路徑、55 個 ruleId。計數：漏裝 84、缺陷 252、分類 180、輪廓 240、量測 240、影片 90、文字 64、生成 5、任務未知 1。

## 已知界線，不列為新增需求

1. 「還不確定」可以走到有待確認事項的計畫，不是強行猜答案。方案方向與已通過驗收分開，這是預期行為。
2. 規則引擎為可核對的教學方法建議，不是硬體效能排名或現場模型測試。固定規則、OCR、取像改善可成為合理答案，不必為了有課程卡而推薦模型。
3. 本輪沒有對所有 1156 條答案組合逐一操作瀏覽器；引擎路徑全列舉、代表流程與狀態交叉用瀏覽器驗證，兩種證據分開記錄。
4. localStorage 的同時多分頁協作、瀏覽器自行清資料及未來格式版本，不在現行功能保證內。本輪未發現單一正常操作流程造成自有有效備份不能還原。
