換情境試著判斷

品質與速度能否一起改善？

產線要縮短延遲，DiffusionAD 看起來恢復較快，但細刮傷偶爾被保留、大面積缺陷又需要較強恢復。

直接減少運算並提高門檻，還是調整噪聲與合成練習後重驗？

看解釋與可接受的取捨

先固定解析度和硬體，分開保留細刮傷、大缺陷及允收正常品。兩尺度與合成設計影響恢復和定位；提高門檻可能壓低誤報卻漏掉細傷。把整套恢復、分割、前後處理時間一起量，在同漏檢要求下比較誤報和覆核量，不能由單步估計直接推論整套最快。

模型專屬因果鏈

實作時逐步核對

主圖已在上方第一遍。這裡只核對每一步要鎖定的設定與為什麼，不再重貼同一張圖。

1
鎖定 one-step norm-guided diffusion recipe

以乾淨 normal support 訓練並保存 denoiser、noise schedule、固定 timestep、norm guidance、precision、loss、seed、ROI/transform 和 checkpoint。

因為：one-step 的定義、重建品質與成本都由這組 state 決定；不能以多步 sampler 的畫面或延遲替代它。

設定核對：工程圖核對：normal support → fixed timestep/norm guidance → denoiser

2
測試圖一次 forward 得到 restoration

test ROI 依同一 recipe 經 one-step denoiser 產生 normal-like restoration，保存 input/restoration pair。

因為：restoration 只是供比較的對照；它可能保留 defect、消除正常 microstructure 或產生自己特有的 artefact。

設定核對：工程圖核對：test image → one-step restoration

3
segmentation head 同看原圖和對照

將 test image 與 restoration 的聯合表示送進 discriminative segmentation path，輸出 pixel anomaly map。

因為：DiffusionAD 的 local evidence 不等於直接相減；segmentation supervision、joint input 與其 synthetic/real policy 決定模型學到什麼。

設定核對：工程圖核對：input + restoration → segmentation map

4
map 經固定後處理才成 candidate

map 依鎖定 smoothing、resize、mask、aggregation、calibration、threshold 與 decision unit 成為 review candidate。

因為：後處理可以隱藏小 anomaly 或改低 FPR；one-step forward 很快也不代表 acquisition 到 hand-off 的完整 P95 可接受。

設定核對：工程圖核對：map → aggregation → calibrated gate

什麼情況不能相信它？

這一區保留完整工程條件，供準備實作或驗收的人逐項核對。

noise/timestep/guidance 導致 defect preservation、erasure 或正常 artefact

可能看到：restoration 或 map 可能對正常亮、對真異常淡；外觀好看無法判斷哪種失敗。

正確下一步：HOLD；以 input/restoration/map 三聯證據、真實 failure images 和低 FPR 分開檢驗。

segmentation head 過擬合 synthetic anomaly 或 restoration artefact

可能看到：模型辨認的是訓練捷徑而非產線異常，real challenge 可能漏檢。

正確下一步：保存 supervision policy、synthetic/real protocol 和 error taxonomy；用 real holdout 驗證。

ROI/照明/焦距/壓縮漂移、tiny defect 或 global logic

可能看到：外部條件主導 restoration 差異，小缺陷低於有效解析度，邏輯問題仍未被表達。

正確下一步：先查 acquisition/effective pixels；對 logical anomaly 改用結構或規則型 evidence path。

原始建置項目

這些設定要一併保存

輸入與版本：兩噪聲尺度引導恢復，再把原圖和估計一起交給分割網路。；關鍵機制：正常影像學去噪，合成異常及遮罩教定位。測試時同一原圖加入兩種尺度的噪聲，高噪聲分支的正常估計 N 引導低噪聲分支估計 R；原圖 A 與 R 一起輸入分割網路產生位置圖。每個尺度用單步估計，不代表整套只呼叫一次網路。；獨立驗證：量 defect erasure、restoration-caused false reject、real low-FPR escape、review load、synthetic-to-real gap 與完整 P95/P99。；失敗處理：先查缺陷可見度與正常涵蓋，再查恢復設定和分數來源。

原始選型條件：DiffusionAD／DRAEM 把原圖與恢復圖一起交給學習式定位網路；DDAD 整合像素差異與適配特徵差異。前兩者需要合成異常與定位訓練，DDAD 則需正常去噪與特徵適配。在同硬體、解析度與漏檢風險要求下，比誤報、延遲和人工覆核量；沒有共同實測就不排名。
