# PatchCore：從正常局部記憶到現場覆核

沿用A-01工件，把來源局部接到特徵、代表庫、最近鄰與人工覆核。第2章展示實際CNN特徵提取；二維教學點、方法示意、第三方重現與原作者案例各自標明證據範圍。

## 1. 只有正常品，PatchCore 可以先做什麼？

先確認正常參考，再留出正常品與缺陷測試；建庫完成還不等於可以放行。

- 先確認建庫影像真的合格，涵蓋允收紋理、螺絲與直邊等正常變化。圖中A/D/E保留來源身分；特徵庫存描述，來源小圖供回查。另留正常與已知缺陷，分別看誤報和漏檢。圖為資料分工示意，不能把這幾個生成局部當作真實訓練／驗證資料集。
- PatchCore使用預訓練視覺特徵；此處免去的是針對這個產品重新訓練特徵模型。整理資料、挑代表子集、建索引、驗證門檻仍要做。
- 異常程度與位置線索交給人工回查原圖和允收規格。不要將高距離當成缺陷種類或根因；缺陷樣本不足時先做探索試驗，逐步補齊驗證。

自我檢查：只有20張正常面板和2張刮傷圖，明天要展示。哪些用來建庫，哪些保留？
核對：從已確認正常影像選建庫資料，另留未入庫正常品與兩張刮傷做初步驗證，保存分割。兩張缺陷只支持演示，不足以宣稱現場漏檢率；後續補批次和缺陷種類。

## 2. 正常外觀怎麼變成可比較的特徵？

整張工件進固定CNN，同位置的回應在鄰域聚合後形成局部描述；可以回查來源，而不是靠符號猜特徵。

- 第一視圖使用既有生成工件，實際執行ResNet50 IMAGENET1K_V2，取layer2的一個通道。原圖位置框、回應图的同位置框、3×3實際數值及平均4.70可以互相反查；這是描述的一個分量，不是異常分數。
- 第二視圖將同一待測位置的layer2與layer3回應並列。每層先作3×3鄰域平均，較深層再雙線性對齊，串接兩層描述；較深層涵蓋的影像範圍較大，但單一通道可能不回應某個缺陷。圖中只顯示少量分量，完整局部特徵還包含其他通道。
- 為可讀性，通道按正常圖的空間變異選定後固定，正常與待測共用模型、通道及前處理。兩張特徵圖各自正規化色階以顯示結構，不能把色深跨層比較成異常程度；標出的描述數值保留原尺度。
- 這次是可重跑的CNN提取教學，沒有訓練或執行PatchCore異常檢測，也不冒稱原論文的WideResNet50基準。輸入ROI直接雙線性縮為224×224，加ImageNet標準化，沒有採權重附帶的resize232與中心裁切。來源、權重SHA、版本、通道與完整數值保存在p03-sources/cnn-features.json。

自我檢查：改成兩倍影像尺寸，正常庫可以完全不動嗎？
核對：不能直接沿用驗收結果。解析度會改變特徵的有效感受範圍與局部外觀；用同一新版流程重建庫並驗正常和缺陷，再比較定位及耗時。

## 3. 為什麼不把所有正常特徵都留下？

coreset用較少代表點保留正常特徵的涵蓋範圍，讓查庫負擔可控。

- 六個來源局部各綁A–F：A/B是表面，C/D是螺絲，E/F是直邊。圖把相同身分帶到二維教學點與保留框，讓被刪的B/C/F能回查代表A/D/E。二維座標為示例設定，沒有宣稱是這些照片或第2章CNN實測投影。
- 圖用六個二維點示範greedy選樣：先選A，再選離已選集合最近距離最大的點D，接著補E。其餘B、C、F各有近的保留代表；實際方法可先隨機投影降低選樣成本，圖不是高維特徵的實測投影。
- 可核算設定：A=(0,0)、B=(0.6,0)、C=(3.7,0.2)、D=(4.2,0.1)、E=(2,3)、F=(2.5,2.8)。此例保留A/D/E；6留3只為教學，不能當推薦比例。縮小庫後用同一留出正常與缺陷比較漏檢、誤報和成本。

自我檢查：只看平均推論變快，就把保留比例從10%降到1%，合理嗎？
核對：先固定同批測試和其他設定，比對罕見但合格的外觀是否被刪掉、缺陷是否仍能抓到，再看P95和記憶體。比例是待驗證的取捨，不能只按速度決定。

## 4. 正常局部與刮傷，查同一個庫會怎樣？

每個待測局部搜尋整個保留庫；最近者可能仍然不夠近。

- 兩個視圖保留A-01原圖、來源放大和同一A/D/E庫。照片示意細紋、螺絲、直邊來源；距離是在特徵空間比較，不是照片像素相減，也不限制同一物理位置。
- 沿用二維L2設定：正常Q=(0.2,0)，到A/D/E約為0.20/4.00/3.50；刮傷Q=(2,5)，約為5.39/5.37/2.00。前者最近A，後者最近E；坐標是教學指定，非由工件照片或實際CNN算出。
- 正常局部很近只表示此局部與庫相似，不能推出整件合格。刮傷也有最近者，但距離可能仍高；後續需看整件分數、位置、原圖及規格。

自我檢查：刮傷的最近參考是直邊，能因此認定刮傷正常嗎？
核對：不能。最近只代表候選中相對最像，仍要看距離大小與同版本門檻，並回原圖確認外觀差異。兩個外觀都帶邊緣線索也不代表工件品質相同。

## 5. 同一組局部距離，怎麼變成整件分數和熱圖？

分數用於分流，保留位置的距離圖用於回查；兩條輸出責任不同。

- 論文先取最大最近L2距離s*，再依最近正常參考附近的距離做鄰域加權。新圖固定s*=2，兩組Q到參考的距離是(2,2.1,2.2)與(2,4,5)，由Eq.7得到w約0.70/0.96、s約1.40/1.93。線長按距離畫；最接近E相同，其他參考遠近改變支持程度。這是獨立可驗算的教學例，不是照片實测或第3章A–F座標的延伸。
- 位置圖將局部距離排回原格，放大並平滑到影像大小。較亮區是回查线索，不能直接當精密缺陷輪廓或刮傷長度；要量尺寸須另做取像校正及邊界驗證。
- 版本差異要寫清：本次查閱作者程式common.py用FAISS IndexFlatL2，回傳平方L2；近鄰查詢可取多鄰居平均，再由patchcore.py取最大patch分數。它與論文的L2及鄰域加權不能混稱同一數值配方；例如本教學L2=2，其平方是4，門檻不能照搬。
- 本教材沒有使用AnomalyDINO的最高1%平均。現場保存距離度量、近鄰數、分數聚合、平滑及門檻版本，分開測誤報和漏檢。

自我檢查：原門檻是按L2距離設定，程式改成FAISS平方L2，可以保留同一門檻數字嗎？
核對：不能。最近鄰排序雖不因平方改變，分數尺度已變；還須確認聚合與加權是否相同。重新校準門檻、重跑留出資料，不能只憑名稱都叫L2就沿用。

## 6. 正常收太少，與缺陷收進去，後果相反

用同一待測與兩個庫狀態，分開看覆蓋不足造成的誤報風險，以及污染造成的漏檢風險。

- 覆蓋不足示例：正常直邊E=(2,3)原本可在A/D/E找到自身，距離0；刪掉E後，最近只剩A，L2約3.61。這是特徵集合的反事實示意，不表示真正驗收可以拿同張建庫圖當測試圖。
- 污染示例：刮傷Q=(2,5)原最近E距離2.00，誤加入相似刮傷G=(2,4.9)後降到0.10。分數降低不一定好，可能是缺陷被當成正常。兩例均固定模型與既有座標，只改库內容。
- 修改庫之前確認參考合格及來源，保留庫版本；修改後正常品與已知缺陷都重測。若是照明、尺度或取像漂移，先修成像，不能將未知外觀全部收成正常。

自我檢查：補了一批參考後，誤報下降，但某種刮傷也不再報警，下一步是什麼？
核對：先隔離新庫與可疑參考，與旧庫跑同批留出影像，查是否混入缺陷、刪掉重要代表或調過門檻。恢復可驗證設定，再同時檢查漏檢、誤報與覆核量。

## 7. 同一新產品，三種方法要重做哪些工作？

共用正常資料與留出測試，對照記憶庫、位置統計、訓練模型的維護差異。

- 三視圖都用A-01作為工作情境。PatchCore保留來源特徵與全庫查詢路徑；PaDiM以各位置正常特徵估計多變量高斯，按同位置Mahalanobis距離比較，圖中三張相同來源小圖代表多張正常影像的角色，不是三筆實測分布證據。換產品須更新庫／索引或重估各位置分布。
- EfficientAD圖限定Teacher–Student局部分支：固定老師、正常資料回饋更新學生、調整後正常回應接近，待測回應差異成為疑點。波形是角色示意，不是實測激活；完整方法另有autoencoder全域分支。換產品需評估重訓與再驗證，速度優勢仍須用相同硬體和工作品質要求實測。
- 公平試做共用資料分割、輸出目的、影像尺度與硬體條件，完整記錄各方法必要設定。分開量建庫或訓練成本、峰值記憶體、暖機後批次1端到端P95、漏檢、誤報與人工覆核量。模型有不同特徵機制，不能假裝其設定完全相同。
- 局部相似不等於組裝順序正確；精密邊界或尺寸任務也不應只靠熱圖。另比較位置規則、監督式分割或校正量測，按真正輸出需求選方法。

自我檢查：工廠每天換產品，但推論節拍很緊，應直接選不需重訓的PatchCore嗎？
核對：把換線建置成本和每件推論成本分開。PatchCore可作快速建庫候選，EfficientAD可作推論效率候選；在同批正常/缺陷資料測品質、P95、記憶體與重建/重訓時間後決定，不只看是否訓練。

## 8. 公開定位案例、作者漏檢與誤報一起看

先拆原圖、人工標註、熱圖與疊圖，再核對整件分數；局部亮對不代表輪廓精確或整件分類正確。

- 前兩視圖來自mtaha-ai公開PatchCore重現的膠囊gallery第1／3行，逐欄保留同一行原像素：input、GT、heatmap、overlay。第一例左側缺陷與亮區對上，但上方另有亮區；第二例紅色半部上緣缺陷與亮區對上，熱區輪廓比標註寬。兩者只支持這些局部定位觀察，沒有可核對的整件分數／門檻，不能宣稱整件分類成功或整體準確率。
- 這是第三方重現，不是PatchCore原作者或本站推論。固定repository commit、原圖SHA與四欄裁切座標均保留；PNG未提供樣本ID及確切訓練配置，不能把README所有設定或指標套到它。後兩圖則是原論文的漏檢與誤報，來源分開。
- FigureS2電纜例有對應局部熱區，但作者分數3.48低於其門檻3.56，所以整件仍為漏檢。熱圖看起來找到位置，不代表決策門檻已通過。S2原圖多個檔名字樣重複，教材不據該字樣宣稱樣本ID；只取同座標局部，數值與錯誤類型按圖說。
- FigureS1正常膠囊例：分數1.22高於作者門檻1.19造成誤報。該類正常變化仍需納入驗證，不能把亮起直接當缺陷；作者圖的顏色與不同類別門檻不可用來排名。
- 後兩例引用原論文S1/S2原像素，未重繪、未補細節，且不是本站模型執行結果。其圖說採作者所述F1最佳門檻的分析；前兩例的第三方重現沒有提供可核對的整件門檻。現場按漏檢代價及覆核容量決定工作點，不直接沿用作者門檻。
- 現場保留參考庫來源/版本、原圖、整圖分數、熱圖與人工判定；跨批次正常及必抓缺陷都納入最後測試，再統計漏檢、誤報、覆核量、P95與記憶體。

自我檢查：熱圖對到缺陷位置，但整圖分數低於門檻，算成功嗎？
核對：若任務是自動把缺陷品送覆核，這仍是漏檢。定位可作診斷證據，但要檢查分數聚合與工作門檻；調整後同時重測正常誤報和缺陷漏檢，不能只挑漂亮熱圖。
